# Studio tutorial asset register

No borrowed clips, logos, music, templates or voice impersonation are included.

| Asset | Origin / permission | Where used |
|---|---|---|
| Studio interface footage | Recorded from the real local Pollframe build in an isolated test browser | Main workflow |
| Opening/closing graphic | Real exported Studio SVG, rasterised at 2× with its actual font; source/date/licence retained | Original motion compositions |
| Poll observations | Pollframe's existing Bundestag dataset, DAWUM / ODC-ODbL; institute and date visible | Demonstration only, not live data |
| Inter | Existing self-hosted Fontsource font, SIL OFL; see `public/licenses/fonts/inter.txt` | Motion titles and selected chart |
| German narration | Local Piper neural synthesis; `de_DE-thorsten-high` model card identifies Thorsten's CC0 dataset. Repository/model-card links below. | Narration, openly identified as synthetic |
| British-English narration | Kokoro-82M v1.0, voice `bf_emma`, Apache-2.0 model; kokoro-onnx 0.4.9 MIT runtime, local production only | Default narration outside the German language setting |
| Intro/outro music | Original D-major/B-minor/G-major plucked theme, generated by `remaster-audio.py`; no external samples or melody | Opening and closing only, ducked under narration |
| Transition sound | Original synthesized tones from the sample production script | Quiet opening bed |
| Captions and script | Written for this tutorial; translated EN/ES captions | Local VTT and transcript |

Voice references:
- https://huggingface.co/hexgrad/Kokoro-82M (Apache-2.0 model card)
- https://huggingface.co/hexgrad/Kokoro-82M/blob/main/VOICES.md (`bf_emma` is British English)
- https://github.com/thewh1teagle/kokoro-onnx (MIT runtime)
- https://github.com/thorstenMueller/Thorsten-Voice (CC0 dataset; author explicitly offers his voice for TTS projects)
- https://huggingface.co/rhasspy/piper-voices/blob/v1.0.0/de/de_DE/thorsten/high/MODEL_CARD
- https://github.com/OHF-Voice/piper1-gpl (production tool, not distributed as part of Pollframe's website)

Piper uses a phonemizer internally, but the soundtrack is neural voice synthesis, **not eSpeak-generated speech**. No paid speech API, cloud renderer or downloaded voice model is shipped to visitors. Only MP4, a poster and subtitles are served by Pollframe.

The visual inspiration example is only a temporary research download under `/tmp`; it is not part of the film or website. Public sharing of an example is not treated as a licence to reuse its footage.

FGW approval data is deliberately not used in this tutorial while the separate commercial-permission question remains unresolved.
